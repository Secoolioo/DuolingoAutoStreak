# DuolingoAutoStreak

Hält eine Duolingo-Streak automatisch: Ein Python/Playwright-Dienst auf einem Linux-Server macht jeden Tag zu einer zufälligen Uhrzeit eine kurze Lesson und schickt das Ergebnis per ntfy aufs Handy.

> Duolingos Nutzungsbedingungen verbieten Automatisierung. Nutzung auf eigenes Risiko.

Status: im Aufbau.
